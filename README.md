# DryRoom

Dehumidifier size calculator: get the right pints-per-day capacity from room size, dampness and ceiling height, plus running cost. Free tool.

## Features
- Pints-per-day sizing from area, dampness, ceiling height and moisture sources with cold-temperature flag
- Dampness reference table and standard-size roundup guidance
- Running-cost estimator from wattage, hours and electricity rate
